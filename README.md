# MindGame

Chess, reimagined: 3D board, five game modes (Classic, Half Board, Four Kingdoms, King of the Hill, Knightmare),
a knight that can also jump 2+2, and computer opponents from Novice to Master.

**Play:** https://itamar-galpern.github.io/lab1/

Run locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
Tests: `npm test` (Node 20+).
